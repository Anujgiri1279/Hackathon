# Hackathon Projects

This repository is a collection of the hackathon projects, prototypes,
experiments, and related work that I create while participating in different
hackathons and innovation challenges.

Each project is organized in its own folder so that its source code,
documentation, setup instructions, demonstrations, and supporting materials
remain easy to find and review.

## Projects

- [`Hackem' Hex/Waste to Worth`](Hackem%27%20Hex/Waste%20to%20Worth/) —
  A sustainability platform that helps users analyse waste, discover reuse and
  recycling options, and generate AI-powered upcycling ideas from text or
  images.

More hackathon projects and work will be added to this repository over time.
